## 06:14-06:38 — SSC Health Check False Positive Investigation

### Root Cause Found & Fixed
- **Bug**: `index.json` had doubled `memory/` prefix in segment file paths
- Every `file` property was `memory/segments/X.md` instead of `segments/X.md`
- `ssc-health.ps1` does `Join-Path $memoryDir $seg.file` where `$memoryDir = memory/`
- Result: checking `memory/memory/segments/X.md` (doesn't exist) → 15/16 "missing"
- **s013-eval-results** also had `path` instead of `file` property (wrong schema from different creation code path)

### Fix Applied
- Created `scripts/fix-ssc-index.cjs` (persistent tool) to fix index paths via Node.js
- PowerShell inline fixes kept failing because `ConvertFrom-Json` serializes PSCustomObjects with original properties, re-adding the prefix
- Node.js script strips `memory/` prefix, validates all 16 files exist, saves clean JSON
- `index.json` lastMaintenance updated to 2026-08-09
- Health check forced run: 16/16 segments healthy ✅

### Key Learning
- Never use PowerShell `ConvertFrom-Json`/`ConvertTo-Json` to edit index.json — it corrupts property names
- Always use Node.js for JSON manipulation of memory index files
